## Goal

미응답 메일 후보를 Claude API(기본 Claude Haiku 4.5)가 "조치 필요"인지 판정하고
한 줄 요약을 붙인다. 놓친 업무에 👍/👎를 남길 수 있고, 설정 화면에서 2주 👍 비율
(G2)과 이번 달 AI 비용(G5)을 볼 수 있다. 월 비용이 상한($5)에 닿으면 AI 판정을
멈추고 규칙 판정만으로 계속 동작한다.

## Out of scope

- 메일 외 항목의 AI 판정, 메일 본문 전체 전송, 스트리밍
- 피드백으로 프롬프트를 자동 조정하는 것

## Approach

**설정·비밀값** — Keychain `anthropic.api_key`. settings 기본값:
`ai_model = "claude-haiku-4-5-20251001"`, `ai_monthly_cap_usd = 5`,
`ai_price_in_per_mtok = 1`, `ai_price_out_per_mtok = 5` (모델을 바꾸면 사용자가
가격도 바꾼다 — 설정 화면에 안내 문구).

**호출 (`ai.rs`)** — `POST https://api.anthropic.com/v1/messages`,
헤더 `x-api-key`, `anthropic-version: 2023-06-01`, `content-type: application/json`.
`max_tokens: 150`, `temperature: 0`.
- system: "너는 사용자의 받은편지함을 돕는 비서다. 메일이 사용자의 답장이나 조치를
  필요로 하는지 판단한다. 뉴스레터, 광고, 자동 알림, 단순 공지는 조치 불필요다.
  JSON 한 줄로만 답한다: {\"needs_action\": true|false, \"summary\": \"40자 이내 한국어 한 줄 요약\"}"
- user: `보낸 사람: {from}\n제목: {subject}\n본문 앞부분: {snippet 앞 500자}`
- 응답 `content[0].text`에서 첫 `{`부터 마지막 `}`까지를 JSON으로 파싱한다.
  파싱 실패 → `needs_action = true`, `summary = None` (놓치는 쪽보다 과하게
  띄우는 쪽이 낫다), 오류 로그.
- `usage.input_tokens`, `usage.output_tokens`를 `ai_usage`에 기록.

**판정 단계 (`sync.rs`)** — Gmail 동기화 직후:
1. 후보 = M1 메일 규칙을 만족하는 항목 (`!last_from_me` && 기준일 경과)
2. `ai_judgments`에 같은 `(thread_id, last_message_id)`가 있으면 건너뛴다
3. 이번 달(로컬) 누적 비용 ≥ 상한이거나 API 키가 없으면 판정하지 않는다
4. 나머지를 동시 2개로 호출, 매 호출 후 누적 비용을 다시 확인한다

**테이블 (`store.rs`)**
- `ai_judgments(thread_id, last_message_id, needs_action, summary, created_at, PRIMARY KEY(thread_id, last_message_id))`
- `ai_usage(id INTEGER PRIMARY KEY, model, input_tokens, output_tokens, cost_usd, created_at)`
- `feedback(source, item_id, vote, created_at, PRIMARY KEY(source, item_id))` — vote = 1 / -1

**놓친 업무 규칙 변경 (`missed.rs`)**
- 메일 후보에 판정이 있으면 `needs_action == true`일 때만 포함, reason에 요약을
  쓰지 않고 `MissedItem.summary`(새 필드)에 넣는다. 이때 Item의 stage를 `Requested`로.
- 판정이 없으면 (AI 꺼짐·상한·키 없음·아직 판정 전) M1 규칙대로 포함하고 reason에
  " (AI 판정 없음)"을 붙인다.
- `feedback.vote == -1`인 항목은 모든 규칙에서 제외한다.

**통계 (`get_stats`)** — `{ month_cost_usd, month_input_tokens, month_output_tokens,
cap_usd, feedback_14d: { up, down, ratio } }`. 비용 = in × 가격in / 1e6 + out × 가격out / 1e6.

**화면** — MISSED 카드와 알림 화면의 각 줄에 요약(있으면)과 👍/👎 버튼. 👎를 누르면
바로 사라진다. 설정 화면에 API 키 입력(저장 후에는 마지막 4자리만 표시), 모델,
월 상한, 가격 두 개, 통계(이번 달 비용 / 상한 막대, 2주 👍 비율).
상한에 닿으면 상단 바에 "AI 판정 중지 (월 상한)" 표시.
