## Approach

**인증** — Notion 내부 통합(internal integration) 토큰. 사용자가
notion.so의 통합 설정에서 만들고, "프로젝트 플래너" 데이터베이스를 그 통합에
공유한다. 토큰은 Keychain `notion.token`. 헤더: `Authorization: Bearer {token}`,
`Notion-Version: 2025-09-03`.

**연결 (`save_notion`)** — 입력: 토큰, 데이터베이스 URL 또는 ID (URL이면 32자리
hex ID를 뽑아낸다).
1. `GET https://api.notion.com/v1/databases/{database_id}` → `data_sources[0].id`
2. `GET https://api.notion.com/v1/data_sources/{data_source_id}` → `properties`
3. 매핑: title = `type == "title"`인 속성, due = 이름이 `마감일`인 date 속성
   (없으면 첫 date 속성), status = 이름이 `진행 상태`인 status 속성 (없으면 첫
   status 속성). status 속성의 `groups`에서 그룹별 option 이름을 읽어
   to_do / in_progress / complete 그룹을 정한다. 그룹 이름은 API 응답 그대로
   비교하되 대소문자를 무시하고 `"To-do"|"To do"`, `"In progress"`, `"Complete"`로
   맞춘다. 맞는 그룹이 없으면 option 이름 `시작 전`/`진행 중`/`완료`로 대신 판정한다.
4. 매핑을 `settings`에 JSON으로 저장 (`notion.mapping`). 실패하면 이유를
   그대로 연결 화면에 보여준다 (예: "통합에 데이터베이스가 공유되지 않았습니다" = 404).

**fetch** — `POST https://api.notion.com/v1/data_sources/{data_source_id}/query`,
body `{ "page_size": 100 }`, `has_more`/`next_cursor`로 이어서 최대 1000행.
요청 간격 350ms 이상 (Notion 속도 제한 대비).

**변환** — 순수 함수 `fn page_to_item(json: &Value, mapping: &Mapping) -> Option<Item>`:
- kind `Task`, title = title 속성의 plain_text 이어붙임 (비면 "(제목 없음)")
- due = date 속성 `start`. 날짜만 있으면(시간 없음) 그 날 로컬 23:59:59를 UTC로
- done = status가 complete 그룹
- stage: to_do → `Requested`, in_progress → `InProgress`, complete → `Done`
- timestamp = `last_edited_time`, url = 페이지 `url`, meta = `{ status_name }`

**놓친 업무 규칙** — `kind == Task` && `!done` && `due < now` → reason
"마감 {N}일 지남", since = due.
