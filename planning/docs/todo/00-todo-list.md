# Open Questions Index

One line per open question. Full detail lives in each item's own file.
Move a row to "resolved" (or remove it) once a report captures the answer.

| File | Status | Summary |
|---|---|---|
| _(example) 260219-1030-01-pricing-tier-name.md_ | open | Need legal sign-off on new tier naming |

## How to add an item

1. Copy `_template.md` to `YYMMDD-HHMM-NN-short-title.md` in this folder.
2. Fill it in.
3. Add a row to the table above.
