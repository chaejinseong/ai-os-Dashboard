## 카드별 데이터

기간 토글(오늘 / 7일 / 30일)은 COMPLETION과 PIPELINE의 "완료"에만 적용된다.
기간 = 오늘 0시에서 N-1일 전 0시부터 오늘 23:59까지 (로컬 시간).

- **COMPLETION**: Notion 작업 중 마감일이 기간 안에 있는 것. DONE = 완료,
  LEFT = 미완료. 퍼센트 = DONE / (DONE + LEFT). 0건이면 "—".
- **BOARD**: 완료되지 않은 작업(Notion 작업 + GitHub 할당 이슈)을 마감 기준으로 나눈다.
  - 오늘: 마감이 오늘 23:59 이전 (지난 것 포함)
  - 이번 주: 내일 ~ 이번 주 일요일 23:59
  - 나중에: 그 이후, 또는 마감 없음
  - 오른쪽 위 숫자 = 세 칸 합계. 막대 = 합계 대비 비율.
- **PIPELINE**: 각 항목의 `stage`로 센다.
  - 요청: 응답이 필요한 메일(M3 이후 AI가 "조치 필요"로 판정), 응답 안 한
    초대, Notion "시작 전", GitHub 할당 이슈
  - 진행: Notion "진행 중", 내가 연 PR
  - 검토: 나에게 리뷰 요청된 PR
  - 완료: Notion 완료 중 마감일이 기간 안에 있는 것
  - 제목 옆 ⚠ 숫자 = 파이프라인 항목 중 놓친 업무 개수. 놓친 업무가 가장 많은
    단계의 줄을 빨간 배경으로 강조한다. ↻ 버튼 = 지금 동기화.
- **MISSED**: 놓친 업무를 오래된 순으로 최대 5개 보여준다. 각 줄에는 서비스
  아이콘, 제목(말줄임), 경과일(🕐 N일)이 있다. 클릭하면 원래 서비스로 이동한다.
  오른쪽 위 ✓ 버튼 = "알림" 화면으로 이동. 서비스별 왼쪽 테두리 색을 쓴다.
- **SCHEDULE**: 오늘·내일 일정을 시간순으로 보여준다. 응답 안 한 초대는 표시를 붙인다.
- 우측 상단 원형 배지 `n건` = 놓친 업무 개수 (사이드바 "알림" 숫자와 같다).

## 상태 표시

- 타이틀바 `● live`: 모든 연결된 소스가 오류 없이 동기화 주기 안에 갱신됐으면
  초록 "live". 동기화 중이면 "syncing", 오류가 있으면 빨강 "error", 네트워크가
  없으면 회색 "offline".
- SOURCES 점: 초록 = 정상, 빨강 = 오류(예: 다시 로그인 필요), 회색 = 연결 안 됨.
- 검색 ⌘K: 캐시된 항목 제목을 화면에서 필터링한다 (서버 호출 없음).

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#0f141c` | 창 배경 |
| `--surface` | `#171d27` | 카드, 사이드바 |
| `--surface-2` | `#1e2531` | 선택된 메뉴, 토글 선택 |
| `--border` | `#262e3b` | 카드 테두리 |
| `--text` | `#e8ebf0` | 본문 |
| `--text-muted` | `#8a93a3` | 라벨(COMPLETION 등), 보조 텍스트 |
| `--accent` | `#e8a54b` → `#e2735a` | 도넛 그라데이션, 로고 |
| `--danger` | `#e2574c` | 놓친 업무, 경고, 배지 |
| `--success` | `#4caf7d` | 완료, live, 연결 상태 |
| `--warning` | `#e0b341` | "나중에" 막대 |

- 다크 테마만 지원한다 (v1).
- 카드: 모서리 12px, 1px 테두리, 안쪽 여백 20px. MISSED 카드는 빨간 테두리를 쓴다.
- 카드 라벨: 대문자, 자간 넓게, 12px, `--text-muted`. 숫자: 굵게, 큰 크기.
- 글꼴: 시스템 기본 (`-apple-system`, `"Apple SD Gothic Neo"`). 숫자는
  `font-variant-numeric: tabular-nums`.
- 아이콘: 선 아이콘 (lucide-react). 서비스 로고는 단색 아이콘으로 대체한다.
  상표 로고 이미지는 넣지 않는다.
